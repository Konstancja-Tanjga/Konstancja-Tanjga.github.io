# konstancja-tanjga.github.io

Sends the bare domain to the portfolio at https://konstancja-tanjga.github.io/portfolio-site/ (repository: portfolio-site).

- `index.html` redirects and carries the same link-preview tags, so a pasted https://konstancja-tanjga.github.io previews as the portfolio.
- `404.html` adds the missing `/portfolio-site` prefix to any other path.
